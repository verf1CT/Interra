# Чат-бот компании «Интерра» на платформе MAX (business.max.ru)

Руководство разработчика и администратора по чат-боту самообслуживания и продаж для платформы **MAX** (`https://business.max.ru/self/chat-bots`) на основе утвержденного сценария.

---

## 1. Архитектура интеграции с MAX

Бот взаимодействует с официальным API MAX (`platform-api2.max.ru`, документация: `https://dev.max.ru/docs-api/`):
- **События платформы MAX** (Webhook / Long Polling):
  - `bot_started` — инициализация диалога и выдача главного меню сегментации (`START_01`).
  - `message_callback` — нажатие inline-кнопок, обработка переходов по дереву сценария через `POST /answers?callback_id=...`.
  - `message_created` — текстовые сообщения от пользователей (ввод телефона, адреса, текста для оператора).
- **Движок бота (`server/src/bot/botEngine.js`)**:
  - Полная поддержка всех 28 шагов сценария из Google Таблицы.
  - Интеграция с биллингом UTM5 (детализация начислений, баланс, обещанный платеж на 10 дней, автотест и сброс порта свитча).
  - Управление выездными мастерами (поиск заявки, выбор и перенос слотов визита).
  - Экспресс- и пошаговая лидогенерация.
  - Режим живого оператора (`OP_01`, `OP_SALES`).

## 2. Команды запуска и тестирования

### А. Локальный симулятор (без токена и без интернета):
```bash
cd server
npm run bot:sim
```
Позволяет пошагово проверить все 28 экранов и кнопок в консоли.

### Б. Автономный запуск с платформой MAX (Long Polling):
```bash
cd server
# Укажите в .env: MAX_BOT_TOKEN=...
npm run bot:max
```
Бот подключается к `https://platform-api2.max.ru/updates` и сразу отвечает пользователям в MAX.

### В. Боевой Webhook на сервере (Production):
```bash
cd server
npm start
```
Webhook URL для MAX: `https://push.interra.ru/api/bot/max/webhook`.

### Г. Автотесты:
```bash
cd server
npm test
```
22 теста Vitest проверяют всю цепочку состояний и формат пакетов MAX API.

## 3. Чек-лист: что нужно от вас для запуска в MAX

1. **Токен бота MAX**:
   - Зайдите в кабинет [MAX для бизнеса](https://business.max.ru/self/chat-bots) в раздел **Чат-боты**.
   - Нажмите `⋮` на нужном боте → **Настройки** → скопируйте **Токен** (строка формата `...`).
   - Передайте мне или пропишите в `server/.env` в переменную `MAX_BOT_TOKEN`.
2. **Адрес вебхука** (если запускаем в продакшене через Webhook):
   - Укажите в кабинете MAX или мы зарегистрируем через API адрес: `https://push.interra.ru/api/bot/max/webhook`.
3. **Параметры Биллинга «Интерра» (UTM5 / API)**:
   - URL API биллинга (`BILLING_API_URL`) и токен (`BILLING_API_TOKEN`).
   - Если API еще настраивается, бот будет работать на встроенном реалистичном моке.
4. **Параметры CRM / Очереди операторов**:
   - Куда слать заявки на подключение новых клиентов (`POST /crm/lead`).
   - В какую систему переводить диалог при эскалации на оператора (Helpdesk, Chat2Desk, Usedesk, Битрикс24 или чат дежурных).
