### Собираемые категории данных:
1. **Personal info → Phone number:**
   - *Collected:* Yes
   - *Shared:* No (не передаётся третьим сторонам)

   - *Linked to user:* Yes
2. **Device or other IDs:**
   - *Collected:* Yes (Firebase Cloud Messaging push token)

3. **App activity → App interactions:**
   - *Collected:* Yes (Firebase Analytics)
   - *Shared:* No
   - *Purpose:* Analytics
   - *Linked to user:* Yes
4. **App info and performance → Crash logs:**
   - *Collected:* Yes (Firebase Crashlytics)
   - *Shared:* No
   - *Purpose:* Analytics / Bug fixing
   - *Linked to user:* No

## 6. Доступ для модераторов (App access / Review credentials)

Так как вход в приложение осуществляется по SMS-коду на номер абонента, Google Play требует предоставить тестовые данные для ревьюера:

- В консоли перейдите: **Содержимое приложения (App content)** → **Доступ к приложению (App access)** → выберите **«Все или некоторые функции ограничены» (All or some functionality is restricted)**.
- Нажмите **«Добавить инструкцию» (Add instruction)**:
  - **Название доступа:** `Subscriber Test Account`
  - **Номер телефона / Логин:** `+79220000000` *(или тестовый номер, согласованный с администраторами биллинга)*
  - **Пароль / SMS-код:** `0000` *(или мастер-код тестового контура)*
  - **Пояснение для проверяющего (Notes for reviewer):**
    ```text
    This is a telecommunications customer service app for Interra ISP subscribers.
    To test the full app:
    1. Enter phone number +7 922 000-00-00
    2. Click "Получить код" (Request SMS code)
    3. Enter verification code 0000
    4. You will gain immediate access to the subscriber dashboard with account info, payment demo, and diagnostics.
    ```
